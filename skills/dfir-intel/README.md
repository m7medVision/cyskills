# DFIR & Intel

Forensics, malware analysis, threat hunting and intelligence.

- **[case-review](./case-review/SKILL.md)**: Reviews a reverse-skill case package for scope readiness, Evidence to Finding to Path traceability, work item coverage, timeline
- **[digital-forensics](./digital-forensics/SKILL.md)**: Use for authorized digital forensics including memory dumps, disk timelines, PCAP investigation, artifact triage, and IR evidence
- **[malware-analysis](./malware-analysis/SKILL.md)**: Use when analyzing suspected malware through static, dynamic, and behavioral techniques, including IOC extraction, YARA or Sigma rules,
- **[threat-hunting](./threat-hunting/SKILL.md)**: Use for blue-team threat hunting, detection engineering with Sigma/YARA, SIEM query design, and incident detection validation.
- **[threat-intelligence](./threat-intelligence/SKILL.md)**: Use for authorized OSINT and cyber threat intelligence that enriches IOCs, campaigns, impersonation, scams, or threat actors from public sources
